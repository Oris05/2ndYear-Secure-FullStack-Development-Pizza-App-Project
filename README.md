Online Pizza Ordering System
This project is a simple online pizza ordering system that supports basic features such as user accounts, menu browsing, a shopping cart, and order confirmation. Customers can choose items, review their cart, and complete the checkout process through an easy-to-use interface.

Part 1: Web Application Development
  Home Page Wireframe
  The home page wireframe was created to:

- Provide an overview of the services (pizza for sale)
- Highlight promotions (Student Deal, 2-for-1, Party Discount)
- Include a quick navigation menu (Register, Login, Cart, Menu, Deals)
- Display popular pizzas 

Sign Up and Login Pages
  Status: Completed
  These pages allow users to:

- Create an account
- Log in
- Access their shopping cart and ordering features

Menu Page
 Status: Completed
 The menu page includes:

- A list of available pizzas
- Prices and descriptions
- Buttons to add items to the shopping cart

Shopping Cart
  The shopping cart allows users to:

- View selected items
- Adjust quantities
- See the total cost
- Proceed to checkout

Order Confirmation
  The order confirmation page:

- Shows the final order summary
- Confirms the purchase
- Completes the ordering flow

Technologies Used
HTML, CSS, JavaScript
Node.js and Express (backend structure)
MongoDB (collections included in the repository)

Purpose of the Project
This project was created as part of a Secure Full-Stack Development module. It demonstrates:

- UI/UX wireframing
- Frontend and backend integration
- Working with MongoDB collections
- Building a simple but functional ordering workflow
